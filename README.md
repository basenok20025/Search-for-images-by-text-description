<h2>Multimodal Image Search by Text Description</h2>

<p>
Разработка системы мультимодального поиска изображений, способной находить наиболее релевантные изображения по текстовым запросам с использованием методов компьютерного зрения и обработки естественного языка.
</p>

<h3>Задача</h3>

<p>
Создать модель машинного обучения для поиска изображений по текстовому описанию, объединяющую визуальные и текстовые признаки в единое пространство представлений.
</p>

<h3>Решение</h3>

<p>
Подготовил и объединил несколько источников данных с пользовательскими и экспертными оценками релевантности пар «текст — изображение».
</p>

<p>
Разработал механизм формирования целевой переменной на основе взвешивания экспертных и crowd-оценок, выполнил очистку данных и фильтрацию чувствительного контента.
</p>

<p>
Построил мультимодальный пайплайн обработки данных: получил семантические эмбеддинги текстов с помощью модели SentenceTransformer и извлёк визуальные признаки изображений с использованием предобученной сети ResNet18.
</p>

<p>
Объединил текстовые и визуальные признаки в единый вектор признаков и обучил несколько моделей регрессии для оценки релевантности пары «запрос — изображение».
</p>

<p>
Реализовал сервис поиска изображений по произвольному текстовому запросу с выводом наиболее релевантных результатов.
</p>

<h3>Результат</h3>

<ul>
  <li>Построил рабочую систему мультимодального поиска изображений по текстовому описанию.</li>
  <li>Сравнил модели Ridge и MLPRegressor, выбрав лучшую по метрикам RMSE и MAE.</li>
  <li>Достиг значения метрики Hit@1 ≈ 7,3% на тестовой выборке.</li>
  <li>Подтвердил эффективность объединения текстовых эмбеддингов и визуальных признаков.</li>
  <li>Сформировал рекомендации по улучшению качества поиска за счёт использования специализированных мультимодальных моделей, таких как CLIP.</li>
</ul>
